# Emberfall: The Hollow Crown
An original turn-based fantasy tactics adventure: four heroes, d20 dice rolls, branching dialogue with skill checks, and a dead king's crown to break.
Single HTML file, no dependencies. Play: https://tmacgoat.github.io/emberfall/
Controls: mouse/keyboard, PS5/Xbox controller (D-pad cursor, Cross confirm, L1/R1 abilities, Triangle end turn), or touch on phones. Installable (Add to Home screen). Progress auto-saves.
